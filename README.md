# Morava Home — Sales Performance Analysis

## Project Overview

This project presents a sales performance analysis for Morava Home, a fictional Czech e-commerce company specializing in household products.

The objective was to transform raw transactional data into an Excel dashboard that provides insights into revenue, profitability, product performance, and regional sales.

## Tools & Skills

- Microsoft Excel
- Data cleaning and validation
- VLOOKUP, IF, SUMIFS, COUNTIFS
- Pivot Tables and Pivot Charts
- Financial KPI calculations
- Data visualization and business analysis

## Dataset

The project uses synthetic data created for educational purposes.

- **900** unique orders
- **200** customers
- **20** products
- **Period:** January–September 2026

## Project Workflow

1. **Data Cleaning:** Removed duplicate orders, handled missing values, and standardized data.
2. **Data Integration:** Combined order records with product and customer information using VLOOKUP.
3. **Financial Analysis:** Calculated net product sales, total costs, gross profit, and gross margin.
4. **Sales Analysis:** Analyzed performance by month, product category, individual product, and city using Pivot Tables.
5. **Dashboard Development:** Created an Excel dashboard with key performance indicators and visualizations.
6. **Business Insights:** Identified sales patterns and developed recommendations based on the results.

## Key Insights

- January generated the highest monthly revenue, while June had the lowest.
- Decor generated the highest total revenue among product categories.
- Storage achieved a gross profit margin of approximately 52%, compared to 44.69% for Decor.
- Regional sales analysis revealed differences in revenue distribution between cities.

## Business Recommendations

1. Investigate opportunities to increase sales of high-margin products, particularly within the Storage category.
2. Evaluate marketing performance across cities before allocating additional advertising budget.
